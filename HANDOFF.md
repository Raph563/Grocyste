# Reprise Grocyste

Au 2 octobre 2026, le CORE 1.0.0 et ses neuf addons signés sont déployés sur Grocy 4.7.1. La qualification finale comprend Python 165, SDK 10, addons 164, HTTP 78, résilience 14 et interruption de migration 4 ; Docker, PHP natif et sous-répertoire sont exercés. Les 26 contrôles de production et le rejeu ciblé passent. Les douze tables métier, le schéma, les objets ProductHelper et les personnalisations sont conservés.

Les quatre anciens services de recomposition sont retirés ; les routes historiques d’administration répondent 410. L’ancien secret n’a plus de vérificateur actif. Le service Android conserve son identité ; les sessions live sont reprises par le propriétaire unique. La sauvegarde générale a été réellement restaurée et comparée.

Les dix dépôts/releases sont publics. Les 23 assets ont été téléchargés anonymement et vérifiés ; les neuf paquets signés ont été installés depuis un cache vide. Les branches par défaut des trois dépôts historiques sont conservées. Les neuf archives sont figées ; ne jamais remplacer une version signée existante. Les reçus et coordonnées privés restent hors de GitHub.

Les huit échecs catalogue historiques restent reproduits et exclus. Aucun APK, nouvel import métier de démonstration ni correctif SQL ProductHelper n’est livré. Les limites et preuves synthétiques sont décrites dans [la livraison](docs/livraison-1.0.0.md).

Le premier workflow public RecipeScaling omettait le checkout voisin RecipeLive requis par son test de contrat. Le correctif de CI récupère la révision qualifiée dans le voisin attendu ; aucun fichier du paquet signé ni tag de release n’est remplacé.

## Ajout du 3 octobre 2026 : catalogue public

Grocyste-Catalog 1.0.0 est le dixième addon, livré séparément avec le CORE 1.0.0 existant. La collection partage 5 098 fiches recettes, 690 produits et 85 observations anciennes de prix publics, sans stock, achat, compte, prescription ni photo privée. Les sources libres sont attribuées par révision ; les recettes commerciales restent factuelles avec lien vers la méthode.

Node 24 (8), extraction wiki (7), navigateur (14), intégration PHP Grocy (4) et cycle de vie (5) passent. La CI du catalogue et GitHub Pages sont verts. La signature et les six téléchargements anonymes sont vérifiés ; le gestionnaire installe ce paquet depuis un cache vide. L’activation conserve les douze tables métier, le schéma, les personnalisations et les neuf addons antérieurs. Aucun chargeur, service ou contrat Android n’est remplacé. Le nouvel addon déclare zéro capacité métier ; aucun import massif n’est lancé. Voir [la livraison](docs/catalogue-public-1.0.0.md).

Les tags et paquets précédents restent immuables. Le bootstrap CORE 1.0.0 conserve ses neuf archives ; l’installation ciblée du nouvel addon et son catalogue signé sont fournis par son propre dépôt.
